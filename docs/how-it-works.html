adb-auto

wireless adb, without the scavenger hunt

Android randomises the debugging port on every toggle and every reboot. adb-auto finds the device over mDNS and connects.

1

Discover

Asks the network who is advertising wireless debugging, and gets the current IP and port.

→
2

Verify

Probes the port before trusting it, so a stale mDNS record can't send you chasing a dead endpoint.

→
only if needed 3

Pair by QR

Never paired? A QR prints in your terminal. Scan it. Skipped whenever the phone is still paired.

→
4

Connect

Attaches the device and clears out stale entries, leaving adb devices clean.

Ports that change

Rediscovered every run, with the last good endpoint cached as a fallback.

mDNS that lies

Cached records outlive the connection, so the port is probed first.

Docker noise

Bridge interfaces echo one phone as a dozen candidates. Only real NICs count.

Lookalike failures

"Refused" means debugging is off. A rejected handshake means lost pairing. Opposite fixes.
